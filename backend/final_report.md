### Token Bucket 限流器

```python
class TokenBucketRateLimiter:
    def __init__(self, rate=120, per=60):
        self.rate = rate  # 120 tokens
        self.per = per    # per 60 seconds
        self.tokens = float(rate)
        self.last_update = time.time()
        self.lock = threading.Lock()
        self.slowdown_factor = 1.0
```

**特点**:
- 平滑限流，避免突发请求
- 自动降速机制（触发限流时降速 50%）
- 线程安全

### 进度跟踪与断点续传

```python
class ProgressTracker:
    def __init__(self, checkpoint_file="sync_progress.json"):
        self.checkpoint_file = checkpoint_file
        self.progress = self.load_checkpoint()
    
    def mark_completed(self, item_id: str):
        # 每 50 个保存一次
        if len(self.progress["completed"]) % 50 == 0:
            self.save_checkpoint()
```

**特点**:
- JSON 格式存储进度
- 支持中断后恢复
- 记录失败原因
